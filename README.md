# Food

An application for tracking food and health goals, built with an "Agentic" design philosophy. This project aims to be a well-designed, fully documented, and end-to-end tested application that records facts about health and nutrition.

## Scope

-   **Tracking**: Record food intake, water, and other health metrics.
-   **Integrations**:
    -   **Withings**: Import weight and body composition data.
    -   **Apple Health**: Sync with "Rings" (Activity) data.
-   **Architecture**: Built on a solid foundation of Event Sourcing using Redux to ensure data integrity and debuggability.
-   **Platforms**: Modern web application with a thin native wrapper for iOS.
-   **Quality**: Zero-tolerance for bugs, verified by a comprehensive E2E test suite.
